## 🚀 Установка и настройка

### 3. Настройка Google Sheets API

#### Шаг 3.1: Создайте проект в Google Cloud

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте новый проект (например, `booking-system`)
3. Включите **Google Sheets API**:
   - Перейдите в "APIs & Services" → "Library"
   - Найдите "Google Sheets API" и нажмите "Enable"

#### Шаг 3.2: Создайте сервисный аккаунт

1. Перейдите в "APIs & Services" → "Credentials"
2. Нажмите "Create Credentials" → "Service Account"
3. Заполните данные:
   - **Service account name**: `booking-bot`
   - **Service account ID**: будет сгенерирован автоматически
4. Нажмите "Create and Continue"
5. На шаге "Grant this service account access to project":
   - **Role**: выберите `Editor` или создайте кастомную роль с доступом к Sheets
6. Нажмите "Continue" → "Done"

#### Шаг 3.3: Создайте ключ сервисного аккаунта

1. В списке сервисных аккаунтов найдите созданный аккаунт
2. Нажмите на него → вкладка "Keys"
3. Нажмите "Add Key" → "Create new key"
4. Выберите формат **JSON**
5. Скачайте файл и сохраните его в корень проекта как `service_account.json`

⚠️ **Важно:** Никогда не коммитьте `service_account.json` в репозиторий!

#### Шаг 3.4: Создайте Google Таблицу

1. Перейдите на [Google Sheets](https://sheets.google.com/)
2. Создайте новую таблицу (например, `Meeting Rooms Booking`)
3. Скопируйте **ID таблицы** из URL:
   ```
   https://docs.google.com/spreadsheets/d/1A2B3C4D5E6F7G8H9I0J/edit
                                        ↑ это ID
   ```
4. Откройте доступ для сервисного аккаунта:
   - Нажмите "Share" (Поделиться)
   - Вставьте email сервисного аккаунта (из JSON-файла, поле `client_email`)
   - Дайте права **Editor**

#### Шаг 3.5: Настройте переменные окружения

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Откройте `.env` и заполните:

```env
GOOGLE_SERVICE_ACCOUNT_FILE=service_account.json
GOOGLE_SPREADSHEET_ID=1A2B3C4D5E6F7G8H9I0J
```

### 4. Настройка Telegram бота

#### Шаг 4.1: Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например, `Meeting Room Bot`)
   - Введите username (должен заканчиваться на `bot`, например `meeting_rooms_bot`)
4. Скопируйте полученный **API Token**

#### Шаг 4.2: Настройте бота (опционально)

В @BotFather:
- `/setcommands` — настройте команды меню
- `/setdescription` — описание бота
- `/setuserpic` — аватарка бота

#### Шаг 4.3: Добавьте токен в .env

```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

### 5. Настройка VK бота

#### Шаг 5.1: Создайте сообщество

1. Перейдите во [ВКонтакте](https://vk.com/)
2. Создайте новое сообщество (тип "Организация" или "Публичная страница")
3. Перейдите в "Управление" → "Работа с API"

#### Шаг 5.2: Создайте ключ доступа

1. В разделе "Работа с API" нажмите "Создать ключ"
2. Выберите права:
   - ✅ **Управление сообществом**
   - ✅ **Доступ к сообщениям**
   - ✅ **Доступ к фотографиям**
3. Скопируйте полученный ключ

#### Шаг 5.3: Включите сообщения сообщества

1. Перейдите в "Управление" → "Сообщения"
2. Включите **"Сообщения сообщества"**
3. Добавьте бота в контакты (опционально)

#### Шаг 5.4: Добавьте токен в .env

```env
VK_BOT_TOKEN=abc123def456ghi789jkl012mno345pqr678stu901
```

## 🛡️ Безопасность

### Защита от race condition
Система использует **asyncio.Lock** для каждой комнаты:
- При попытке бронирования слот блокируется
- Выполняется повторная проверка доступности
- Только после подтверждения слот записывается в таблицу

### Валидация времени
- ❌ Запрет бронирования на прошедшее время
- ✅ Округление до шага 30 минут
- ✅ Максимальная длительность — 3 часа
- ✅ Рабочие часы: 9:00 — 18:00

### Защита от инъекций
Все пользовательские данные очищаются перед записью в Google Sheets:
- Удаляются опасные символы в начале строки (`=`, `+`, `-`, `@`)
- Ограничивается длина (макс. 500 символов)
- Экранируются специальные символы

### Хранение секретов
- ⚠️ **Никогда не коммитьте** `.env` и `service_account.json`
- ✅ Добавьте их в `.gitignore`

## FAQ

### Q: Бот не запускается, ошибка "Service account not found"
**A:** Убедитесь, что файл `service_account.json` находится в корне проекта и путь указан в `.env`.

### Q: Ошибка "Spreadsheet not found"
**A:** Проверьте ID таблицы в `.env` и убедитесь, что сервисный аккаунт имеет доступ к таблице.

### Q: Бот не отвечает на сообщения
**A:** Проверьте логи в `booking_system.log`. Возможные причины:
- Неверный токен бота
- Проблемы с подключением к интернету
- Бот не добавлен в сообщество (VK)

### Q: Как посмотреть все бронирования?
**A:** Откройте Google Таблицу — все данные хранятся в листе `bookings`.

### Q: Можно ли изменить шаг бронирования?
**A:** Да, в `config.py` измените `BOOKING_STEP_MINUTES = 30` на нужное значение.

### Q: Как изменить рабочие часы?
**A:** В `config.py` измените `WORK_DAY_START` и `WORK_DAY_END`.
