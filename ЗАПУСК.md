# 🚀 Инструкция по запуску

## Что было исправлено

**Проблема:** vkbottle создает свой собственный event loop внутри `bot.run_polling()`. 
Когда пытаешься запустить два бота в одном процессе — возникает конфликт:
```
RuntimeError: Cannot run the event loop while another loop is running
```

**Решение:** Использовать `multiprocessing` — каждый бот в отдельном процессе:
- **Telegram-бот** — работает в основном процессе
- **VK-бот** — работает в отдельном дочернем процессе (своим независимым event loop)

---

## 📋 Команды для запуска

### 1. Активируй виртуальное окружение
```bash
source venv/bin/activate
```

### 2. Запусти систему
```bash
python3 main.py
```

### 3. (Опционально) Тест Google Sheets
```bash
python3 test_db.py
```

## 🔍 Если что-то не так

| Ошибка | Решение |
|--------|---------|
| `ModuleNotFoundError` | `source venv/bin/activate` |
| VK-бот не запускается | Проверь токен в `.env` |
| TG-бот не отвечает | Проверь токен в `.env` |
| Ошибка Google Sheets | Проверь доступ сервисного аккаунта к таблице |
